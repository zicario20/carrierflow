# Project Skills

These skills are vendored in this repository so every contributor using Codex
gets the same workflows and reference material. Keep their directories under
version control; update them deliberately from their listed upstream sources.

The Architect, Cyber Neo, and UI/UX Pro Max have been adapted from their
Claude-oriented releases to use this repository's `.codex/skills/` layout.
Their upstream MIT licenses are kept beside the corresponding artifacts.

Superpowers includes its complete set of fourteen workflows. Graphify was
installed with `graphify install --project --platform codex`; its hook and
project guidance live in `.codex/hooks.json` and `AGENTS.md`.
