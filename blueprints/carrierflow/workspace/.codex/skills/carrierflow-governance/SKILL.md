# CarrierFlow governance

Work autonomously within the assigned role and leave verifiable evidence.

1. Architect owns system contracts, scope and blueprint consistency.
2. Superpowers owns implementation discipline: TDD, systematic debugging, verification and checkpoint.
3. Cyber Neo owns security. It may patch scoped repository vulnerabilities, run tests, document remediation and notify. It must escalate deletion, secret rotation/exposure, paid resources, external irreversible changes and production access.
4. UI UX Pro Max owns tokens, 44 px controls, non-color status, accessibility and EN/ES parity.
5. Graphify owns memory. Query graph before broad exploration if graph exists; run graphify update . after modifications, using py -m graphify if graphify CLI is unavailable.

Preserve tenant isolation, driver safety/privacy and confirmed product rules. Escalate only material product decisions or external irreversible action; otherwise choose documented safe implementation.
